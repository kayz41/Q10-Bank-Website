# Question 10 — Stanbic Bank Uganda Loan Website

A two-page bank loan-products and personal-loan application front-end practical.

## Files
- `index.html` — loan product cards and comparison table
- `personal-loan.html` — sample personal-loan application form
- `dlac.css` — shared external stylesheet

## Asset note
The homepage references `hero-bank.jpg`, which is absent from the original Question-10 folder. It has not been fabricated; add an approved image when available.

## Run locally
Open `index.html` in a browser. The application form is a classroom front-end demonstration and does not submit banking information to a bank.
